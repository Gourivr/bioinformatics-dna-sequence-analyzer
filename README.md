## Bioinformatics DNA Sequence Analyzer for DNA Composition, Transcription and Translation

## Project Description

The Bioinformatics DNA Sequence Analyzer is a command-line Python program designed to perform basic analysis of DNA sequences.

The program allows the user to calculate GC content, find the reverse complement of a DNA sequence, transcribe DNA into RNA, translate RNA codons into amino acids, compare two DNA sequences, and view a final analysis report.

## Features

- DNA sequence validation
- Calculation of A, T, G, and C base counts
- GC content calculation
- Reverse complement of a DNA sequence
- DNA to RNA transcription
- RNA codon translation into amino acids
- Comparison of two DNA sequences
- Final analysis report
- Menu-based interaction
- Basic input error handling

## Requirements

- Python 3.x

No external Python libraries are required.
