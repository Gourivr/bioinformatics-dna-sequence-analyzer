# Project Statement

## Problem Statement

DNA sequences contain important biological information, but manually analyzing DNA sequences can be time-consuming for basic tasks. This project provides a simple command-line Python program that allows users to perform basic analysis of DNA sequences in an organized way.

## Scope of the Project

The project focuses on basic DNA sequence analysis using Python. It accepts a DNA sequence from the user and performs operations such as base counting, GC content calculation, reverse complement generation, DNA to RNA transcription, RNA codon translation, and comparison of two DNA sequences.

The project is designed for basic educational and bioinformatics purposes and does not perform advanced biological sequence analysis.

## Target Users

- Students learning Python and basic bioinformatics
- Beginners interested in DNA sequence analysis
- Students studying basic genetics and molecular biology concepts
- Users who want to perform simple DNA sequence operations through the command line

## High-Level Features

- DNA sequence validation
- Counting of A, T, G, and C bases
- GC content calculation
- Reverse complement generation
- DNA to RNA transcription
- RNA codon translation into amino acids
- Comparison of two DNA sequences
- Final analysis report
- Menu-based command-line interaction
- Basic input validation and error handling
